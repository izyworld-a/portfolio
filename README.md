# Israel Enweji — Portfolio

My personal portfolio site: Frontend Developer & UI Designer based in Enugu, Nigeria.

**Live:** https://izyworld-a.github.io/portfolio

## Built with

- **React 18** — components, not pages
- **Vite** — dev server and build
- **Plain CSS** — custom design system (custom properties), no CSS framework
- Deployed on **GitHub Pages**

## Design system

Matches my CV's visual identity: Inter typeface, `#2B5CE6` accent, light editorial layout.

## Developing

```bash
npm install
npm run dev      # local dev server
npm run build   # production build to /dist
```

## Deploying

The `main` branch holds the source; the built site is deployed via GitHub Pages.
